# Icons over the target (pack "target-icons"): the skill's icon floats up over the target's head when the skill is
# cast. One choice per line for the members: <skill id> [seconds] [@<effect class id>]  # name | optional description
# The icon is a flipped copy of the member's own Icon.utx skill_i.skill<id>, shown by a new effect added to the skill's
# ShotAction in LineageSkillEffect.u, so it plays on every cast that reaches the target (also when a debuff is
# resisted) and stays for a fixed time (default 5 s), not for the debuff's real duration.
# @<id>: the game plays this skill through l2_<id>_skill instead of its own class. Every other skill playing that
# class shows the icon too. The client picks a skill's class elsewhere (probably skillgrp.dat, out of scope), so a
# skill without its own class needs @<id>: a new l2_<id>_skill class for it is never played (Noblesse Blessing and
# Slow, 2026-11-08), and the build refuses it. The class number comes from a probe build (scripts/New-EffectsExperiment.cs
# --probe), which shows it over the target. Probe results 2026-11-09: Noblesse Blessing 1048, Slow and Curse Poison
# 1168, Arcane Chaos and Sleep 1069.
# Not on L2Dex (no icon or effect class): 1224 Surrender to Poison, 1383-1385 Mass Surrender to Fire/Water/Wind.
